# H 路线合并归档

归档日期：2026-08-12

目的：把活动仓库中的旧编号式路线、其专用实现资产和历史运行输出退出活动区，使
README、START_TASK、ROADMAP、PROGRESS 和活动 docs 只以 H0–H6 作为研究阶段入口。

边界：

- 原始 Evidence 只移动，不改写；
- 用户已有 dirty worktree 在移动前保存为 recovery 快照；
- H 仍需复用的通用代码保留在活动目录；
- 技术 ABI/schema 的版本号不等同于路线阶段，只有仍被运行代码依赖时才保留；
- `legacy-active/` 保存退出活动目录的文档、脚本、配置、测试和专用源码；
- `generated/` 保存不应留在活动树的本地运行/环境输出；
- 恢复时先查看 `recovery/`，再按 `legacy-active/` 内的原相对目录复制回仓库根目录。

持久化边界：

- Git 版本化本 README、`MANIFEST.sha256`、`SYMLINKS.tsv`、`recovery/`，以及
  `legacy-active/` 中除 `docs/runtime-evidence/` 和 `__pycache__/` 外的 272 个可移植文件；
- `legacy-active/docs/runtime-evidence/`、`generated/`、checkpoint 和 Python cache 保持
  本机只读，不进入普通 Git；
- 干净 clone 可以恢复旧源码、配置、测试、文档和工作树快照，但完整历史运行 Evidence
  仍依赖本机归档；`MANIFEST.sha256` 只证明本轮冻结时的内容与完整性，不代替外部制品托管。

本归档不是新的需求来源，不得从这里自动恢复旧路线、阈值或任务。

`MANIFEST.sha256` 从本目录出发按路径排序，覆盖全部 25097 个常规 payload 文件；可用
`sha256sum -c MANIFEST.sha256` 完整复核。`SYMLINKS.tsv` 单独冻结符号链接的相对路径和
目标。两个清单自身的 SHA256 记录在活动 `docs/EVIDENCE.md`。

ROS build/install/log、模型下载 metadata 与 Python cache tree。生成物可以重建，但此轮
按用户要求先归档而不是删除。
