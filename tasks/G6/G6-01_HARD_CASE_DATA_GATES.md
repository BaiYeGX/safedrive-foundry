# G6-01 困难样本窗口与数据门禁

- 状态：PENDING
- 所属阶段：G6 反事实数据飞轮与策略改进
- 前置依赖：G5-04

## 目标

将闭环运行中的接管、近失效、策略分歧和高不确定性片段转化为高质量训练候选，同时阻止脏数据进入训练集。

## 范围

- 定义事件触发器、前后时间窗、优先级和去重逻辑。
- 汇聚专家、VLA、世界模型、安全层及仿真真值信号。
- 建立同步、完整性、泄漏、分布、标签冲突和隐私门禁。
- 生成可查询的数据卡与困难样本清单。

## 完成标准

- 困难样本可自动采集、去重、分层并追溯来源。
- 不合格样本被隔离且原因可解释。
- 数据版本可重建，不覆盖既有基准测试集。

## 验证方法

- 对人工构造的接管、近碰和误触发片段验证窗口正确性。
- 重放同一日志，比较样本 ID 和摘要一致性。
- 执行门禁测试并审查通过/拒绝样例。

## 断点记录

中断时记录数据版本、已处理日志、门禁统计、争议样本、失败原因和下一步。
