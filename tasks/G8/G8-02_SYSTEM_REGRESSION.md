# G8-02 全系统回归、OOD 与实时性评测

- 状态：PENDING
- 所属阶段：G8 系统级验证与成果交付
- 前置依赖：G8-01

## 目标

按冻结协议完成常规、长尾、OOD、故障注入和资源压力下的系统级闭环评测。

## 范围

- 覆盖路线跟随、交叉口、换道、动态避障、遮挡、恶劣条件和组合长尾。
- 测试传感器延迟/丢帧、模块超时、模型失效和通信异常。
- 记录安全、任务完成、舒适、效率、20ms 控制周期抖动及端到端时延。
- 监测 GPU、CPU、内存、磁盘、温度和长稳运行。

## 完成标准

- 冻结矩阵全部运行或按协议标记缺失原因。
- 关键安全门禁和实时性要求有明确通过/失败结论。
- 每个失败可定位到日志、配置、场景和软件版本。

## 验证方法

- 自动汇总运行清单并检查缺失、重复和损坏产物。
- 对关键案例跨种子复跑并人工抽查回放。
- 比较历史阶段基线，识别非预期回归。

## 断点记录

中断时记录矩阵完成度、最后场景、运行 ID、失败队列、资源状态和恢复命令。
