# G7-01 Agent 工具、权限与审计治理

- 状态：PENDING
- 所属阶段：G7 Agent 自动化与可审计研究闭环
- 前置依赖：G6-04

## 目标

建立面向仿真研究的受控 Agent 工具层，使自动操作可授权、可重放、可审计、可停止。

## 范围

- 定义场景生成、运行、查询、分析、数据登记和报告工具 schema。
- 采用命令白名单、路径沙箱、资源限额、超时与人工批准边界。
- 记录输入、输出、版本、决策理由、错误和产物引用。
- 提供 dry-run、幂等、恢复和紧急停止机制。

## 完成标准

- Agent 不能绕过白名单执行任意命令或修改冻结资产。
- 每次工具调用都有结构化审计轨迹和稳定 ID。
- 中断后能根据运行状态安全恢复或回滚临时任务。

## 验证方法

- 对合法、非法、越权、超时和重复调用做测试。
- 重放一条完整审计轨迹并核对产物。
- 注入工具错误，验证停止、隔离和恢复行为。

## 断点记录

中断时记录工具版本、权限策略、测试结果、未解决威胁、审计样例和下一步。
