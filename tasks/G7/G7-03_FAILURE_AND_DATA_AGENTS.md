# G7-03 失败分析与数据策展 Agent

- 状态：PENDING
- 所属阶段：G7 Agent 自动化与可审计研究闭环
- 前置依赖：G7-02

## 目标

实现两个受控 Agent：一个进行多源日志根因分析，另一个依据数据门禁生成训练候选和数据卡。

## 范围

- 失败分析 Agent 对齐规划、控制、VLA、世界模型、安全层和仿真日志。
- 生成根因假设、支持/反驳证据、置信度和复现实验建议。
- 数据策展 Agent 执行查询、去重、分层、质量检查和版本登记。
- 禁止 Agent 自行修改标签真值、验收阈值或冻结测试集。

## 完成标准

- 已知故障集上的根因定位达到预设准确率并能表达不确定性。
- 数据策展结果通过 G6 数据门禁且全链路可追溯。
- 两类 Agent 的错误输出被检测、隔离并留档。

## 验证方法

- 用带已知根因的故障注入集盲测失败分析 Agent。
- 对同一数据请求重复执行并比较清单和版本摘要。
- 红队测试幻觉证据、越权修改与数据污染行为。

## 断点记录

中断时记录 Agent 版本、评测集、当前准确率、数据版本、红队失败项和下一步。
