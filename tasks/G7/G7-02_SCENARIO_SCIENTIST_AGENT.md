# G7-02 场景科学家与反例搜索 Agent

- 状态：PENDING
- 所属阶段：G7 Agent 自动化与可审计研究闭环
- 前置依赖：G7-01

## 目标

实现能够提出可检验场景假设、调用搜索器发现反例并形成证据链的场景科学家 Agent。

## 范围

- 将自然语言风险假设转化为受约束场景参数和评价目标。
- 编排场景生成、批量仿真、结果查询和反例最小化工具。
- 对失败进行复现确认，避免把随机波动当作反例。
- 输出假设、实验、观察、结论和证据引用。

## 完成标准

- Agent 可完成至少三类风险假设的端到端实验闭环。
- 发现的反例可复现、可最小化并具有来源证据。
- 工具调用和结论均满足 G7-01 权限与审计约束。

## 验证方法

- 使用已知反例检查召回能力和错误结论率。
- 重复运行相同任务，比较实验方案与核心结论稳定性。
- 人工审查若干证据链是否支持结论。

## 断点记录

中断时记录假设队列、Agent 配置、已运行实验、反例 ID、验证状态、错误和下一步。
