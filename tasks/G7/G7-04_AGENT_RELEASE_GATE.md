# G7-04 Agent 净收益与发布门禁

- 状态：PENDING
- 所属阶段：G7 Agent 自动化与可审计研究闭环
- 前置依赖：G7-03

## 目标

量化 Agent 自动化相对人工脚本流程的覆盖率、效率、正确性与治理成本，只发布能证明净收益的能力。

## 范围

- 构建代表性任务集和人工基线。
- 评估成功率、错误率、实验覆盖、时间、算力、人工干预和审计完整度。
- 执行越权、提示注入、证据伪造、资源耗尽和中断恢复测试。
- 定义允许自动、必须审批和禁止自动的能力清单。

## 完成标准

- Agent 在目标任务上具有可量化净收益，且安全门禁全部通过。
- 高风险动作保留明确人工批准点和默认拒绝策略。
- 发布报告包含适用边界、已知失败和回退方案。

## 验证方法

- 对相同任务进行人工/Agent 配对实验。
- 运行治理与红队测试套件并检查审计日志。
- 关闭大模型服务，验证系统仍可回退到手工可执行流程。

## 断点记录

中断时记录任务集版本、配对结果、红队状态、待定权限、发布结论和下一步。
