# G5-02 交互式潜空间世界模型

- 状态：PENDING
- 所属阶段：G5 世界模型风险预测器
- 前置依赖：G5-01

## 目标

训练能根据不同自车候选动作预测多模态交通未来的轻量世界模型，重点服务风险评估而非追求视频生成效果。

## 范围

- 设计共享场景编码、动作条件、时序状态转移和多模态解码结构。
- 预测未来占用、参与者状态或紧凑潜变量，并表达不确定性。
- 支持多候选动作批量 rollout、混合精度和有限显存训练。
- 建立训练配置、检查点、推理接口和实验追踪。

## 完成标准

- 模型可在单张 RTX 4080 上训练与推理。
- 相比简单基线，在关键预测和风险相关指标上有明确增益。
- 对至少两种候选动作产生可区分且合理的未来分布。

## 验证方法

- 运行过拟合小样本、完整验证集和 OOD 场景测试。
- 做无动作条件、无交互模块等消融。
- 检查显存、吞吐、数值稳定性和检查点复现。

## 断点记录

中断时记录模型配置、数据版本、检查点、最佳指标、异常日志、消融状态和下一实验。
